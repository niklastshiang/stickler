# Security

Please report vulnerabilities **privately** via
[GitHub's private vulnerability reporting](../../security/advisories/new), not as a public issue.
Stickler is a hobby project: there are no guaranteed response times, and only the latest
release is looked after.

Relevant are, for example: downloads of models and datasets (Hugging Face, GitHub, Zenodo),
`stickler remote` (SSH, Hugging Face token, RunPod API key) and parsing of audio, MIDI and
MusicXML files.
