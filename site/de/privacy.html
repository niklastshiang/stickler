    Datenschutz

    Die App

    Stickler arbeitet auf deinem Computer. Deine Songs, die Noten und deine Einstellungen bleiben dort; nichts wird irgendwohin geschickt. Es gibt kein Konto, keine Cloud und keine Statistik.

    Die App geht nur online, um herunterzuladen, was sie braucht, und fragt vorher: beim ersten Start die zwei Modelle und die Programme, mit denen sie laufen, und wenn du zum ersten Mal eine Schlagzeugspur speicherst, das Modell Demucs. Das kommt von den Servern für Python-Pakete (pypi.org, download.pytorch.org, github.com) und von den eigenen Servern der Modelle (bei Beat This! die JKU Linz). Wie bei jedem Download sehen diese Server die IP-Adresse deines Computers.

    Diese Website

    Diese Seite setzt keine Cookies, verfolgt niemanden und lädt nichts von anderen Servern: Schrift, Bilder und Video kommen von der Seite selbst.

    Sie liegt bei GitHub Pages. GitHub speichert die IP-Adresse jedes Besuchs zur Sicherheit in seinen Server-Protokollen; was GitHub damit tut, steht im GitHub General Privacy Statement (Englisch).
