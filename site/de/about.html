    Wie es entsteht

    Stickler entsteht mit Claude, einer KI von Anthropic, die den Code schreibt; was es tut und wie es aussieht, entscheide ich. Jede Änderung wird getestet, bevor sie zählt, und der ganze Code ist offen auf GitHub, unter der Lizenz GPL-3.0-or-later.

    Stickler trainiert keine eigenen Modelle. Es bringt offene Modelle aus der Forschung zusammen und misst, wie gut sie bei echten Songs sind; die Zahlen stehen im Bericht des Projekts (Englisch).

    Dank und Lizenzen

    • ADTOF hört die Schläge; sein trainiertes Modell ist frei für nicht-kommerzielle Nutzung (CC BY-NC-SA 4.0).
    • Beat This! findet Schlag und Takt (MIT-Lizenz).
    • Demucs trennt die Schlagzeugspur ab (MIT-Lizenz).

    • Diese Seite ist in Figtree gesetzt (SIL Open Font License).
    • Der Beispielsong ist „Fluffing a Duck“ von Kevin MacLeod (incompetech.com), lizenziert unter CC BY 4.0.

    Stickler liefert nie ein Modell mit: Die App lädt jedes auf deinem Computer herunter, nachdem sie seine Lizenz genannt hat.
