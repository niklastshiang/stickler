Privacy

The app

Stickler works on your computer. Your songs, the sheet music and your settings stay there; nothing is sent anywhere. There is no account, no cloud and no statistics.

The app goes online only to download what it needs, and asks before it does: on the first start the two models and the programs they run with, and the first time you save a drum track, the Demucs model. These come from the Python package servers (pypi.org, download.pytorch.org, github.com) and from the models’ own servers (JKU Linz for Beat This!, Hugging Face for Demucs). Like any download, these servers see your computer’s IP address.

This website

This site sets no cookies, uses no tracking and loads nothing from other servers: its font, pictures and video come from the site itself.

It is hosted on GitHub Pages. GitHub records the IP address of every visit in its server logs for security; what GitHub does with it is described in the GitHub General Privacy Statement.
