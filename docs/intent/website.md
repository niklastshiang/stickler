# Intent: a website for Stickler

Confirmed by the owner on 2026-11-18 (interview). The spec is SPEC.md, "Website".

- **Outcome:** one static page in plain HTML and CSS, in English and German, with a few
  separate pages (about, privacy), built in TuxTalk's order: a hero with the animated overview,
  how it works in steps, the honest numbers, a song next to its sheet, the models with sizes and
  licences, download cards, privacy, uninstalling.
- **User:** drummers who are not technical.
- **Success:** someone who is not technical lands on the page and has Stickler installed and
  running without help, on the Mac including "Open Anyway", shown with pictures.
- **When:** built now; online with release 8 (the Mac `.dmg`).
- **Constraint:** GitHub Pages from the repository at `stickler.tshia.ng`; no generator, no
  tracking, no cookies, JavaScript only where nothing else works; self-hosted fonts; light and
  dark following the system; a look of its own that matches the app (not TuxTalk's, not
  GymMane's).
- **Open:** the typeface; the owner does not like TuxTalk's.
- **Out of scope:** a documentation site (report, CLI guide), Spanish, a static site generator,
  the owner's VPS. The older "GitHub Pages site" idea is dropped.
