# ADR 0007: GPL-3.0-or-later instead of MIT

- Status: accepted
- Date: 2026-11-15

## Context
Stickler was published under MIT (releases 1–4). With the GTK app it becomes something people
install and use, shipped as a Flatpak and an AppImage. The owner asked whether the GPL fits the
app better and chose it: changed versions that are passed on should stay free.

Everything Stickler ships or builds on is compatible with the GPL: GTK, libadwaita, PyGObject and
Verovio (LGPL), the Leipzig font (OFL), numpy, PyYAML, mido and uv (BSD/MIT/Apache). The models'
weights are not part of the code and keep their own licences (ADR 0002).

## Decision
- **Licence:** the whole project (library, benchmark, adapters, app, scripts, documentation) is
  under the GNU General Public License, version 3 or later, from release 5 on.
- **Earlier releases:** releases 1–4 stay under MIT; whoever took code from them keeps that right.
- **Where it shows:** `LICENSE` (the GPL text from gnu.org), `pyproject.toml`, `CITATION.cff`,
  the AppStream MetaInfo, the About dialog, README and CONTRIBUTING.

## Consequences
- Whoever passes on a changed Stickler must do so under the GPL, with its source code.
- Much of the code was written with an AI assistant. How far such code is protected by copyright
  is unsettled, so the GPL's protection may be weaker than for code written by hand (the owner's
  information, not legal advice).
- GNOME Circle accepts any OSI licence; most GNOME apps are GPL-3.0-or-later, so this matches.
